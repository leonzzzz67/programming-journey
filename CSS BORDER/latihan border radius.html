Lathian Border radius

Border Radius akan membuat pojok di bagian elemen tumpul atau tidak berbentuk siku, tapi berbentuk lingkaran. Biaasnya nilai border radius ditentukan dengan satuan piksel, persen, em, dll. Kalau diberikan nilai 100% berarti sudut lingkaran penuh, yakni 360 derajat. Silakan coba-coba eksperimen sendiri dengan mengganti nilai pada properti border-radius
